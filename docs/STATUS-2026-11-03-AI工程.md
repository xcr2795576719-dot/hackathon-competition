## 四、已知限制（答辩时主动说）

1. **T2 十四款没有二手样本和 30 天历史价**。它们的报告只能基于「新机现价 vs 首发价」，
   结论固定 `wait`，理由写「暂无二手样本，先等价格稳定」。这不是 bug，是数据没采到；
   想变成 `buy`/`avoid`，需要 D 补 `used_samples.json` 和 `prices_history.json`。
2. **T2 轻划痕图是合成的**：在 T1 完好图上叠了 3 条细划痕 + 1 处边框小磕碰。
   它能验证「同一张图连跑 3 次」的稳定性，但不能替代真机拍摄对「细微划痕 vs 污渍」的区分。
   E 的真机照片还没拍；补拍后覆盖 `docs/prompts/test-images/` 同名文件、重跑脚本即可。
3. **买入线 65% → 80% 是演示校准**。种子数据 95新/新机价 77.5%～80%，65% 永远不触发，
   20 份会全 `wait`。理由和回退方法写在 `docs/prompts/report.md` 第三节；
   接真实闲鱼数据后应按品类重新定阈值。
4. **数据仍是 seed**。`data/prices_*.json` 和 `data/used_samples.json` 的 `source` 都是
   `seed`；首页「更新于 23 小时前」是种子时间，不是真实采集时间。
5. **部署未动**。这次只跑本地 `npm run build` + `npm run start -- -p 3100`；
   服务器/域名/AI Works 提审仍是队长侧待办。
