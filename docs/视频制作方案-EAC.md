## 制作管线（EAC 工具链调用顺序）

1. record-browser：录制真实网页操作（语义选择器脚本；演示站待定：本地 localhost:3000 最稳 / WorkBuddy 链接带 sharecode / EdgeOne 预览）
2. stock-download：开场空镜 2~3 个（数码/手机特写，pexels，记作者与许可进 credits）
3. beats：配乐节拍分析 → 剪辑点卡拍、转场落重拍
4. captions：字幕烧录（文案见下）+ 导出 SRT
5. 时间线精修：科技感冷色调 preset、图表出现瞬间轻微变速+推近运镜
6. render 渲染成片 + 导出 SRT/剪映草稿（答辩后可人工续剪）
