# EAC 插件使用教程（自己动手版）

> 你在 DSH 对话框里直接用自然语言指挥我操作，或者按本教程自己在 EAC 工作台里点。
> 所有能力都通过 DSH 对话下达——你说「做什么」，我调用对应工具。
> 下面的「指令示例」是可以原样发给我说的话。

## 0. 基础概念（30 秒看懂）

- **项目（Project）**：一个视频工程。包含素材、时间线、调色配置。一个项目一个成片。
- **素材（Asset）**：导入的视频/图片/音频。来源两种：本地文件导入、内置浏览器录屏。
- **时间线（Timeline）**：素材按顺序排列 + 每段的起止时间 + 调色。这是成片的最终形态。
- **任务（Job）**：所有耗时操作都是任务（录屏/分析/渲染/转写），提交后轮询状态直到完成。
- **修订号（revision）**：每次改时间线 revision +1。防止覆盖你手动调整——我每次提交都带最新 revision。

## 1. 创建项目

对我说：
> 用 EAC 建一个视频项目，标题「XXX」，1920x1080，30fps

我会调用 eac_project_create，返回 projectId（记下来，后面都用）。

## 2. 素材来源（两种）

### 2a. 录屏（录你的网页/应用）
对我说：
> 用 EAC 录屏 http://localhost:3000/ 这个页面，依次：等 2 秒 → 点 Apple 按钮 → 等 1 秒 → 点 iPhone 13 → 等 3 秒 → 向下滚动 → 等 2 秒

我调用 eac_job_submit(type=record-browser)，录完自动导入项目。
**要点**：
- 点击目标用「按钮上的文字」或「链接地址」定位（如点 text=Apple 或 a[href='/prices/xxx']）
- 如果同文字出现多个，会报错——加限定（button:has-text('Apple')、a[href=...]）
- 每步之间用「等 N 秒」留出页面响应时间，动画页面多等
- 录屏是无声的（页面没有声音），1080p30

### 2b. 本地文件导入
对我说：
> 把 D:\xxx\视频.mp4 导入到 EAC 项目

我调用 eac_asset_import。支持 mp4/图片/音频。

## 3. 查看素材（分析）
> 分析一下刚导入的素材，多长、什么分辨率

我调用 eac_job_submit(type=analyze)，返回时长/分辨率/编码——**提交时间线前必须知道每段素材的精确时长**（差 0.1 秒都会报错）。

## 4. 时间线（把素材串成片）
对我说：
> 时间线这样排：开场 0-8.4s、行情页 8.4-25s、验机页 25-35s、报告页 35-44s、收尾 44-50.7s

我调用 eac_timeline_update（带最新 revision），每段clip = {素材路径, 在成片里的起始秒, 取用时长, 从素材第几秒开始取}。
**规则**：取用时长 ≤ 素材时长；相邻 clip 的 start 要接上（前一个 start+duration）。

## 5. 调色（整体观感）
在提交时间线时一起说：
> 整体调色：冷色调偏蓝、压一点曝光、加暗角和锐化

对应参数：exposure（曝光±）/ contrast（对比）/ saturation（饱和）/ temperature（色温冷暖）/ vignette（暗角0-1）/ sharpen（锐化0-2）。
**流程**：我先提交一版 → 用 grade-preview 生成调色前后对比帧给你看 → 你说哪里不对 → 我改参数重提交 → 再看。最多 4 轮。

## 6. 渲染出片
> 渲染

我调用 eac_job_submit(type=render)，几分钟出 mp4（1080p30）。
渲染完我会拷到项目根目录并抽帧质检（黑屏/错位/文字可读性）。

## 7. 其他能力（按需）
- **配乐**：搜无版权音乐（jamendo/pexels），下载导入，铺在音轨
- **节拍卡点**：分析配乐 BPM，剪辑点对齐节拍
- **字幕**：成片本身不烧字幕；导出 SRT 外挂（提交系统支持），或导入剪映烧录
- **转写**：有语音的素材转文字+时间轴（我们的录屏无声，用不上）
- **导出剪映草稿 / FCP7 XML**：想手动精修时导出工程文件，在剪映/PR 里继续

## 8. 昨晚踩过的坑（避免重复）
1. record-browser 的点击目标如果页面上有多个同文字元素会报错 → 加限定
2. 时间线 clip 的 duration 超过素材实际时长会报错 → 先 analyze 拿精确时长
3. track 参数必须是数字（0=主视频轨），不能写 "v1"
4. look 调色参数必须是对象不是字符串
5. 渲染 51s 视频约 4 分钟，耐心等
6. 字幕不烧录在成片里 → 要么 SRT 外挂交付，要么剪映烧录

| 导出剪映草稿 | eac_job_submit(export) |
